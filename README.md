# reqtrace-mcp (working title)

An MCP server that makes Claude Code prove its work: every change traced to a requirement, every requirement traced to a passing test that actually exercises it, independently reviewed, with an evidence report a human signs off. Plus an eval that measures whether it helps.

**Status:** M0 (spec). See [`docs/SPEC.md`](docs/SPEC.md), [`docs/DECISIONS.md`](docs/DECISIONS.md), [`docs/DEVLOG.md`](docs/DEVLOG.md).

Built with Claude Code. Inspired by public DO-178C concepts; not a qualified tool and makes no compliance claim. All examples are synthetic.
